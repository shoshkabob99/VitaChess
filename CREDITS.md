# Credits

Vita Chess is made by shoshkabob.

**Lua Player Plus Vita** by Rinnegatamante, which runs the game (its `eboot.bin` is included in
the VPK). Licensed under GPLv3. https://github.com/Rinnegatamante/lpp-vita
Lua Player Plus Vita is built on vita2d by xerpi, LuaJIT, and VitaSDK.

**Logo:** `assets/art/logo-source.png`. Before public release, record its source and licence here.

**Interface font:** Inter by Rasmus Andersson (`assets/fonts/`), SIL Open Font License 1.1
(see `assets/fonts/LICENSE-Inter.txt`). https://rsms.me/inter/ The bitmap versions in
`assets/fonts/bitmap/` are rendered from it by `tools/make_fonts.py`.

**LuaDEV R0** (PSP test build): the PSP Lua interpreter whose EBOOT.PBP is included in the PSP
zip, collected and documented by João Matias Godinho under the MIT license.
https://github.com/jcnmsg/LuaDEV-R0-PSP

**Piece sprites** are rendered from the Unicode chess symbols in these fonts:
- DejaVu Sans (Classic, Flat, Neon sets): DejaVu Fonts license (Bitstream Vera derived).
- GNU FreeFont FreeSerif (Staunton set): GPLv3 with the font exception.
- GNU Unifont (Pixel set): GPLv2+ with the font embedding exception / SIL OFL 1.1.

**Puzzles** (`assets/puzzles/puzzles.txt`) are from the Lichess puzzle database, released
under CC0 (https://database.lichess.org/#puzzles), selected from the rating-balanced subset in
FeXd/puzzle-chess (https://github.com/FeXd/puzzle-chess). Every solution is checked by the
tests in `tests/test_rules.lua`.

**Evaluation tables** follow Tomasz Michniewski's "Simplified Evaluation Function"
(Chess Programming Wiki). Perft test positions and counts are from the Chess Programming Wiki.

Sound effects, the title emblem, and the LiveArea art were generated by the scripts in `tools/`
(piece shapes from DejaVu Sans's chess symbols).
